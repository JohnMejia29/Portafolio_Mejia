# 💾 PORTFOLIO.EXE - Portafolio Retro Windows 95 / 98 & Full-Stack CMS

Portafolio profesional interactivo desarrollado con estética retro de sistema operativo (Windows 95/98 + Terminal Linux) y tecnologías modernas para **John Franklin Mejia Chamaya** (Ingeniero en Sistemas Computacionales).

---

## 🚀 Características Principales

- 🪟 **Retro OS Window Manager:** Sistema de ventanas flotantes arrastrables, minimizables a la barra de tareas, maximizables y con control de z-index.
- 🕹️ **ARCADE.EXE:** Mini-juegos retro interactivos (Snake.exe y Football.exe con física y marcador).
- 📜 **SYSTEM_LOGS.EXE:** Registro de eventos del sistema y telemetría en tiempo real.
- 🔐 **ADMIN_CONTROL_PANEL.EXE:** Panel de control de administración con PIN de seguridad para:
  - Gestionar mensajes de contacto recibidos en tiempo real.
  - CMS de Proyectos (Crear, Editar, Eliminar y Subir portadas).
  - Configuración de Perfil (Subir foto de perfil/avatar, subir archivo CV PDF, actualizar biografía y redes).
  - Moderación del Libro de Visitas (Guestbook).
- 📄 **Visualización y Descarga Automática de CV:** Botón `CV_RESUME.PDF` que abre y descarga automáticamente el CV actualizado.
- 📟 **Terminal Linux Interactiva:** Soporte de comandos (`help`, `projects`, `skills`, `contact`, `cv`, `clear`, `matrix`, `date`).
- 📼 **Tech Stack Cassette & Floppy Disks:** Visualización dinámica de tecnologías con animaciones mecánicas y LEDs retro.
- 🌐 **Internacionalización (i18n):** Cambio instantáneo de idioma Español / Inglés.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5 Semántico, Vanilla CSS3 (Variables, Grid, Flexbox, CRT Scanlines, Pixel Art), JavaScript ES6+ Modular.
- **Audio:** Web Audio API (Efectos de sonido 8-bit sintetizados sin archivos externos).
- **Backend:** Node.js, Express.js.
- **Base de Datos:** JSON Database persistente con API RESTful y carga de archivos en Base64.

---

## 💻 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/JohnMejia29/Portafolio_Mejia.git
   cd Portafolio_Mejia
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor local:**
   ```bash
   npm run dev
   ```

4. **Abrir en el navegador:**
   ```
   http://localhost:3000
   ```
